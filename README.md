## 🇬🇧 English

### Overview

A collection of classic JavaScript programming practice problems with solutions, created as teaching material for front-end students. Each problem includes a description, an example input/output, and an implementation in `assets/js/script.js`.

### Topics Covered

- String reversal
- Palindrome check
- Finding the maximum number in an array
- Factorial calculation
- Prime number check
- Removing duplicates from an array
- Finding a missing number in a sequence
- Capitalizing the first letter of each word
- Anagram check
- Finding a pair of numbers that sum to a target value
- ...and more.

### Tech Stack

HTML, JavaScript (vanilla).

### Getting Started

Open `index.html` in your browser, or open `assets/js/script.js` directly to read the problems and their solutions.

## 🇸🇦 العربية

### نظرة عامة

مجموعة من تمارين برمجة JavaScript الكلاسيكية مع حلولها، أُعدّت كمادة تعليمية لطلاب تطوير الواجهات الأمامية. كل تمرين يتضمن وصفاً، مثالاً على المدخلات/المخرجات، وتطبيقاً فعلياً في `assets/js/script.js`.

### المواضيع المغطّاة

- عكس نص (String).
- التحقق من كون النص متناظراً (Palindrome).
- إيجاد أكبر رقم في مصفوفة.
- حساب المضروب (Factorial).
- التحقق من العدد الأولي.
- إزالة التكرارات من مصفوفة.
- إيجاد الرقم المفقود في تسلسل.
- تكبير أول حرف من كل كلمة.
- التحقق من كون كلمتين جناساً (Anagram).
- إيجاد زوج أرقام يجمعان لقيمة مستهدفة.
- ...والمزيد.

### البنية التقنية

HTML، JavaScript (خام).

### التشغيل

افتح `index.html` في المتصفح، أو افتح `assets/js/script.js` مباشرة لقراءة التمارين وحلولها.
